# Input data (not redistributed here)

Download the public files and place them as follows:

- `data/uci/processed.cleveland.data`, `processed.hungarian.data`, `processed.switzerland.data`, `processed.va.data`
  from the UCI Machine Learning Repository, "Heart Disease" dataset (https://archive.ics.uci.edu/dataset/45/heart+disease).
- `data/frmgham2.csv`: Framingham Heart Study teaching dataset (NHLBI BioLINCC, https://biolincc.nhlbi.nih.gov/teaching/).
  Access terms are set by BioLINCC; the file is not included in this repository.
